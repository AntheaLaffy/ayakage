# 向 VTube Studio 靠拢

MVP 的范围见 [MVP.md](MVP.md)。后续按实际直播体验扩展：

1. **真实模型与捕获兼容性**：收集不同 Cubism 导出版本的可复现问题；验证 niri / Portal / OBS 实际录制，完善遮罩、特殊混合与高分屏；增加性能与稳定性基准。
2. **更好的追踪**：模型专属校准、眼神 / 嘴型调节、自动眨眼、麦克风口型、可选集成追踪进程、更多手机追踪输入。
3. **直播操作**：按键组合、按住表情、道具与多模型、场景预设、音频动作同步、窗口置顶和合适的桌面全局快捷键 Portal 接入。
4. **生态接口**：评估 VTube Studio 插件协议兼容、虚拟摄像头、进程间透明画面传输。每项需有实际使用场景和兼容性测试。
5. **发布体验**：在已有 Linux CI 打包与运行检查基础上，扩展 AppImage / Flatpak、自动升级与崩溃诊断；现有门禁见 [CI.md](CI.md)。

这些是未来工作，当前版本不把它们标记为已实现。模型制作继续交给现有编辑器，推流和场景合成交给 OBS。
