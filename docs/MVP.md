# Ayakage 0.1：首个 MVP

依据 `talk.md`：以 Linux / Wayland 为主要平台，兼容现有 Live2D 模型，完全开源的运行时；长期向 VTube Studio 的使用体验和功能靠拢。首版要完成可以操作、可以接入真实面捕、可以交给 OBS 的直播闭环。

## 首版验收

- 原生桌面应用，导入完整模型目录中的 `.model3.json`，读取真实 `.moc3` 和纹理，保留模型源文件。
- 接收 OpenSeeFace 标准二进制 UDP 数据，显示连接状态；支持选脸、校准、平滑、失联回中。
- 头部、眼睛、眉毛、嘴部追踪；参数映射可编辑，可手动检查模型参数。
- 读取模型声明的表情和动作，通过按钮及快捷键触发。
- 舞台拖动、缩放、复位；单独输出窗口提供透明、绿幕与纯色背景，主界面不进入直播画面。
- 保存应用设置和每个模型的映射、视图、热键；重新启动可恢复。
- Wayland 全局快捷键通过显式本机命令接口和 niri 绑定实现，无需读取输入设备。
- 提供可重复的构建、启动、面捕接入、OBS 捕获和验证说明。

## 实现边界

使用 Mocari 0.4.0 的模型运行时和 wgpu 渲染，前端使用 egui / eframe。摄像头识别交给独立运行的 OpenSeeFace。本版不包含模型编辑器、自动安装面捕环境、VTube Studio 插件 API、手机追踪、道具系统、Spout、虚拟摄像头或 VNet。这些留在后续路线图，首版不宣称已达到 VTube Studio 完整功能水平。

模型兼容性以实际样例验证结果为准；实验性运行时不等于支持所有 Cubism 版本和全部模型效果。透明窗口与 OBS 最终捕获的 alpha 分开验证，提供绿幕作为明确可用的捕获路径。
